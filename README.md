Control your HID Streetlight by using 5 relays.

Ideally by using 4 channel solid state relay for 36 Watt Philips BTA Fluorescent Ballast and 1 relay Philips BPL for 18 Watt. This doesn't need additional relay since it using series ignitor.

For Large version use 4 channel 30A relay, 1 relay for 100 Watt Philips BSN Ballast, 1 relay for 125 Watt Philips BHL Ballast, 1 relay to switch on/of BAG 250W/400W Ballast, and 1 relay to switch between 250W (NO) and 400W (NC) Mode.
Use additional Relay to switch on and off the semi-parallel ignitor and connect with 100W ballast relay signal.

For small version the best fixture that I can use is Philips HRC 502 Street light, but make sure to modify to E40/Mogul Base first or use E27 to E40 adapter.

For the large version I'm going to try on Philips HRC 511 in the future.
